## 六、配方调度模型（当前实际实现）

**结论**：`MutableRecipesLogic` 不覆写 `serverTick`，完全复用 GTCEu 的 `RecipeLogic.serverTick()`（与 gtlcore 的 `MultipleRecipesLogic` 一致）。
**一条合并配方承载当前全部可执行候选**，运行中推入的新料在本次结算后的重搜里被收进下一条配方；
并行池不分摊（每条候选独立吃满机器结构并行），搜索期只做并行核算与聚合模拟，真正扣料在 `Host#consumeInputs`。

**实现位置**：

- `api/machine/logic/MutableRecipesLogic.java`：`gtlsupb$collectBatchParallels`、`gtlsupb$transformCandidate`、`gtlsupb$scaleCandidate`、`Host`、`gtlsupb$sleepWhenIdle`。
- `api/machine/logic/MultiTypeMutableRecipesLogic.java`：零能耗多类型机器的合并入口。

**并发与查询**：并发批次调度、`getConcurrentThreads()` 与 `IConcurrentBatchHatch` 已删除；并发批次仓仅保留已发布注册 ID 与占位提示，不产生逻辑效果。`recipeQueryBudget` 与 `planCacheTicks` 已删除；普通单配方路径走 gtlcore 的“首条候选”，多配方合并路径按 gtlcore `MultipleRecipesLogic` 使用完整迭代器，由并行与 EU 预算终止。

**持久化**：无线配方的 `wirelessEuTickInputs` 单独存 `wireless_eut`，读档时重新包装为 `WirelessGTRecipe`。

**约束**：不在 `resetRecipeLogic()` / `interruptRecipe()` 里清空批次（成型回调晚于 NBT 读取，清空会丢进度，规则 27）。

**待游戏内验证**：运行中推料能否立即开新批次、多批次 EU/t 扣电、输出仓满时逐批等待、存档重进后批次恢复。

## 七、空闲退订与催化剂（2026-11-03 最终状态）

**机器空闲退订**：`MutableRecipesLogic.serverTick()` 在并发路径末尾调用 `gtlsupb$sleepWhenIdle()`。
条件与 GTCEu `RecipeLogic.serverTick()` 的空转分支一致：无批次、`isIdle()`、`lastRecipe == null`、
`keepSubscribing() == false`、`recipeDirty == false`、`lastFailedMatches == null`；满足即 `subscription.unsubscribe()`。
推料/样板变化仍由 `markLastRecipeDirty()` + `updateTickSubscription()` 唤醒（样板总成 `gtlsupb$wakeControllers()`）。

**维核样板总成空闲**：`gtlsupb$tickCatalystRequests()` 通过 `gtlsupb$catalystScanRequested` 做稳定态短路：
无待补清单/在途链接/计算中的计划且无重扫请求时直接返回，不再遍历全部样板槽解析 NBT、也不再对每个
催化剂键做 `MEStorage.extract(SIMULATE)`。样板变化（`onPatternChange`）与供给写入（虚拟标记落槽）会置位。

**催化剂**：`CatalystPatternWrapper` 把催化剂输入从 AE 可见输入中彻底剔除（AE 不索取材料、不需要虚拟令牌）；
执行推送时把紧凑数组还原成原样板下标、催化剂位留空；机器侧由样板 NBT 催化剂清单 + 虚拟原料标记匹配。
“0 倍率进图”与 reusable 令牌路线均已撤销（`GraphRecipeSlotMixin` 已删除）。

**Jade 输出**：`gtlsupb:concurrent_batches` 聚合全部批次物品/流体产出；同种按类型合并（忽略 NBT），
合计用 BigInteger，≥100 万科学计数法；原生输出栏、进度条、机器模式行均对 `MutableRecipesLogic` 机器隐藏
（`RecipeOutputProviderMixin`、`WorkableBlockProviderMixin`、`MachineModeProviderMixin`）。
`lastRecipe` 为批次执行配方（真实数量）。
