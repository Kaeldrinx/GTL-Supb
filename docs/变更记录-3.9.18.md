# 变更记录 — 3.9.18（2026-11-02）

## 机器配方逻辑

- **恢复并发批次**：`RunningBatch` 列表 + `startOneBatch` / `tickBatch` / `settleBatch` / `syncBatchDisplay`，
  每条配方独立进度、独立扣电、独立产出，互不阻塞。
- **扣料与开跑 1:1**：扣料从 `getRecipe()` 移入 `startOneBatch()`，`matchRecipeInput` → `handleRecipeInput` → 入列，
  修复"消耗 N 份只产出 1 份"（1000 → 250 的错配）。
- **单配方批次核算**：新增 `gtlsupb$buildSingleBatchRecipe()`，并行只按该配方自身材料核算，
  产出/消耗天然同倍。
- **移除分配算法**：删除 `AllocationAlgorithm`、`FairAllocationUtils` 与 FAIR 分配，改为顺序核算，
  修复"材料被平分"。
- **搜索节流**：`START_INTERVAL_TICKS = 5`，降低合成延迟与 tick 消耗。
- **结算修复**：进度到达时长必须结算，避免机器永远停在 WORKING。
