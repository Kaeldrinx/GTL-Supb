## 阅读顺序建议

1. `项目上下文` → 了解工程如何构建与启动；
2. `机器配方逻辑` → 理解并发批次与产出/消耗账目；
3. `样板绑定系统` → 理解样板如何驱动机器；
4. `TIPS规范` / `API标准` → 后续开发的写作规范；
5. 需要定位问题时查 `性能与排查`，需要回溯行为变化查 `变更记录`。
