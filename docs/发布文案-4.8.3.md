# GTL-Supb 4.8.3 发布

---

## 新增

**超限FTB任务集成仓**

新增 `overlimit_ftb_quest_integration_hatch`。该仓绑定玩家 UUID，并按玩家所属 FTB 队伍处理任务，可连接 AE 网络：

- 从自身连接的 AE 网络取料提交任务；
- 任务奖励写入同一队伍任务仓连接的 AE 网络；
- 支持检测、自动提交、奖励入网三个开关；
- 支持检测间隔设置；
- 支持 gtlcore 无线 ME 网络；
- Jade 显示绑定玩家。

FTB 任务界面的底部功能按钮已移除，手动提交通道仍然保留。

**Jade 绑定玩家显示**

以下部件/机器现在会显示绑定玩家：

- 超限FTB任务集成仓
- 超限量子纠缠仓
- 超限ME驱动器
- 虚空能源吸收器
- 超维能量稳定枢纽

**维核样板总成倍率模式侧栏**

新增独立的倍率模式侧栏：

- 显示当前识别到的宿主产出倍率；
- 提供“识别一次宿主倍率”按钮，按需重新识别，不持续占用 tick；
- 支持项目内多台倍率机器及 GTLAdditions 伪神之煅炉的倍率识别。

**维核样板总成打包侧栏**

样板打包功能移入独立侧栏，并加入机器模式识别：

- 按 gtlcore 写入样板的 `patternQuickUploadRecipeTypes` 识别机器模式；
- 模式按钮支持滚动、中文翻译；
- 新增“识别扫描样板”按钮，可即时重建模式列表；
- 可选择“全部”或指定机器模式打包，避免混包。

## 修复

**超限ME驱动器**

原 ME 驱动器已改名为超限ME驱动器（`overlimit_me_drive`），并修复了独立使用时无法为 AE 任务提供材料的问题。现在它可以被同一 AE 网络中的 FTB 任务集成仓正常读取，也支持 gtlcore 无线 ME 网络。

**AE任务取料提交**

先 `SIMULATE` 探测可提取量，再 `MODULATE` 实际提取，避免直接提取时库存状态不匹配导致失败。

**虚空能源吸收器玩家绑定**

修复未绑定时不会重试绑定的问题：扩大自动绑定半径，并加入低频重试；现在 Jade 可正确显示绑定玩家。

**能量强加载按队伍隔离**

虚空能源吸收器与超维能量稳定枢纽的能量广播现在按发射者所属 FTB 队伍隔离，只向该队伍强加载区块内的接收器供电，避免跨队伍供能。

**样板产出倍率接入 AE 计算**

维核样板总成在运行时按宿主机器的产出倍率重写 AE 样板细节：样板输入输出数据不变，但 AE 下单计算会按机器实际倍率折算输入量。玩家无需手动修改样板倍率。

## 优化

**超级终端搭建与拆除性能**

本次优化了多方块搭建与拆除的执行性能：

- 结构候选数组在一次操作内缓存，避免重复生成；
- 候选到物品的转换结果缓存，减少重复计算；
- 玩家物品处理器复用，降低反复 capability 查询；
- 超级终端收纳单元只查找一次并在整个拆除流程中复用；
- 拆除时复用掉落物的 AEKey，减少重复解析；
- 搭建时复用已有方块状态，避免重复读取。

## 升级提示

1. 删除 `mods` 中的旧 JAR，只保留 `GTL-Supb-4.8.3.jar`。同 MOD ID 多份 JAR 会导致启动问题。
2. 原 `me_drive` 注册 ID 已改为 `overlimit_me_drive`。旧存档中的原 ME 驱动器方块会失效，升级前请先拆除。
3. 使用倍率机器时，将样板放入维核样板总成，并在倍率模式侧栏识别宿主倍率；样板本身无需手动改倍率。
