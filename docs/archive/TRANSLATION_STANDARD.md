# GTLSupb 翻译规范（顺序 · 数量 · 质量）

> 目的：让翻译工作有固定流水线、固定数量口径、固定质量门槛，避免"顺序混乱 / 数量不齐 / 质量参差"。
> 适用范围：`assets/gtlsupb/lang/zh_cn.json`、`en_us.json`（共 601 键，中英必须键集一致）。

---

## 一、翻译顺序（固定 8 步，不允许跳步）

| # | 步骤 | 产物 / 判据 |
|---|---|---|
| 1 | **键审计**：代码引用 ↔ 语言文件双向核对（字面量 + 动态拼接双判定） | 缺失键 = 0；未引用键 = 0（或列入待删清单） |
| 2 | **术语归一**：按下方术语表统一（ME 网络 / 无线电网 / 无线蒸汽能电网 / 闪存 / 已启用·已禁用） | 全文扫描：旧称 0 处 |
| 3 | **版式统一**：全角标点、成对括号、`§8\|§r` 分隔、颜色语义 | 版式自检 0 问题 |
| 4 | **读实现取硬信息**：改写前必须读机器/仓室源码（分配算法、并行口径、消耗与供给、限制） | 每条文案都能指到源码行 |
| 5 | **内容改写**：按"数量标准"重写各行（定位 → 特性 → 机制 → 限制） | 行数符合标准；禁止清单 0 命中 |

| 8 | **打包**：资源 + Java（若动了引用）一起构建 | `BUILD SUCCESSFUL` |

> 铁律：**未读实现不得改写**（第 4 步前置）；**未过自检不得打包**（第 8 步后置）。

## 二、数量标准（统一口径）

### 2.1 行数标准（按对象层级）—— **已定为统一 6 行**

| 对象 | 标准行数 | 结构 |
|---|---|---|
| 多方块机器 tooltip | **6 行**（统一，不再分级） | 1 定位 + 1 特性条 + 3 机制 + 1 限制 |
| 仓室 / 部件 tooltip | **2–3 行** | 1 定位 + 1–2 机制 |
| 单方块机器 tooltip | **1–4 行**（复杂机器如虚空吸收器可到 6） | 功能 + 数值 + 限制 |
| GUI 标签 / 状态行 | **1 行** | `名称：值`，不换行 |
| 消息 / 提示（chat、Jade） | **1 行** | 直接陈述结果 |

**编号规则**：`tooltip.N` 为内部标识，裁剪后**允许保留原编号（允许空洞）**，不为了连号去做键名重排；新增行时使用"当前最大编号 + 1"。

#### 待裁剪清单（>6 行的 6 个族，目标 6 行）

| 族 | 现有 | 需删 | 建议删除的编号（依据"保留机制/数值，删结构常识与重复"） |
|---|---|---|---|
| `multiblock.microcosm_foundry` | 10 | −4 | `.5`（主机与模块独立处理，与 `.3` 重叠）、`.6`（成型即可运行，常识）、`.8`（自动连接/断开，结构常识）、`.9`（87 层，结构常识） |
| `multiblock.steam_modular_factory` | 8 | −2 | `.7`（界面查看蒸汽池，弱信息）、`.4`（主机驱动子模块，与 `.3` 重叠） |
| `multiblock.universal_factory` | 8（idx 0–6,8） | −2 | `.2`（动态并行描述，与 `.3` 公式重叠）、`.8`（需成型/原料不足，常识）；编号空洞随裁剪保留 |
| `multiblock.universal_voltage_regulator` | 8 | −2 | `.5`（解锁等级决定最高电压，与 `.4` 重叠）、`.7`（绑定状态可查看，弱信息） |

执行方式：从 `GTLSupbMachines` 的 tooltip 列表删除对应 `Component.translatable(...)` 引用 → 删除中英对应键 → 行数清单复核 ≤6。

### 2.2 长度标准

- 单行 ≤ **40 个全角字符**（约 80 半角），超出必须拆到另一行或删减；
- 一行只承载 **1 种**硬信息；
- 特性条 ≤ 3 个标签，标签 ≤ 6 字。

### 2.3 键数标准

- 中英**键集完全一致**（`sets-equal=True`）；
- 同一族的键命名同构（`...tooltip.N` 连续、无空洞；删除行时同步删键，不留孤儿）。

## 三、质量标准（四类硬信息 + 禁止清单）

### 3.1 允许（每条必须命中其一）

1. **做什么**：这台机器/部件的处理范围（具体产物或物料，不写配方类型枚举）；
2. **需要什么**：仓室、等级、模块、绑定、催化剂等前提；
3. **数值/公式**：并行口径与公式、倍率、间隔、上限；
4. **限制/代价**：什么时候不工作、不消耗什么、什么不可用。

### 3.2 禁止（命中即改写）

- 配方类型注解（`配方类型：xxx（XXX_RECIPES）`）——GTCEu 自动列出，**永不手写**；
- 口号式对比（"顶替 N 台""一座顶多台"）；
- "无需 / 不必 / 即可" 类空承诺；
- 复述机器名或常识（"熔炉能烧东西""多方块要成型"）；
- 实现细节（"只搜索当前选中的类型""自动识别"）；
- 内部枚举名、键名、类名；
- 与特性条重复的内容。

### 3.3 依据要求

每条文案必须能指到**源码位置**（文件 + 行号）；找不到依据的删掉而不是改写。

## 四、术语表（唯一写法）

| 统一写法 | 禁止出现 |
|---|---|
| ME 网络 | AE 网络 / AE网络 / ME网络（无空格） |
| 无线电网 | 寰宇控制网 / 无线寰宇控制网 |
| 无线蒸汽能电网 | 无线蒸汽网 |
| 闪存 | 数据棒 |
| §a已启用 / §c已禁用 | 开 / 关 / 已开启 / 已关闭 |
| 倍率 | 倍乘 / 倍数（同一语境二选一，统一用"倍率"） |
| 并行 | 并行数（指代同一量时统一用"并行"） |

状态行版式：`名称 §8| §r数值 §8| §r§e数值§r 单位`

## 五、颜色语义（唯一分配）

`§7` 基础说明（行首不再重复加灰）｜`§b` 系统/机制名词｜`§d` 模块/特殊｜`§6`/`§e` 数值｜`§a` 正向/启用｜`§c` 负向/禁用/限制｜`§l` 强调（仅标题性词）｜分隔符统一 `§8|§r`
