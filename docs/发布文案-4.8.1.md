# GTL-Supb 4.8.1 发布

---

## 详细版

### 修复

**虚空能源吸收器关不掉**

开关状态此前没有落盘，只有等到下一次自然存档才写入。玩家关掉开关后立刻退出重进，会回滚到上一次保存的“开”。

现在开关、自动绑定玩家都会立即标记存档，改变后立刻同步到客户端。

**寰宇执序者 / 时序共振增幅阵列一号电路不启动**

这两台机器的基础配方是“只有电路、没有产出”的占位配方，而配方收集环节会把所有没有物品或流体产出的候选直接丢弃，导致放一号电路也永远进不了运行状态。

现在只有真正需要产出的机器才会过滤空产出配方；同时修掉了“无输入配方算不出并行”被误判为不可运行的问题。

**碎界采集器部分配方不运行**

同一处过滤会让输出被概率处理清空的配方被误杀，表现就是某些配方放着材料也不动。修复后这些配方正常进入候选池。

**挖掉寰宇执序者，模式识别栏里的机器不返还**

模式识别栏（56 格）的机器此前不参与掉落。现在破坏主机时会把栏内所有物品掉落在主机位置。

**蒸汽能矿石集成中枢顶掉 GTLAdditions 的天基无尽矿石处理**

两个模组都会从集成矿石处理器的配方复制一份到自己的配方类型，且都沿用了原配方的注册名，后注册的会覆盖先注册的。现在本模组的副本改用 `gtlsupb:steam_*` 独立命名，两边各自保留。

### 优化

**虚空能源吸收器 tick 开销**

- 两个开关都关闭时直接退订服务器 tick，机器完全不再运行；
- 无线广播与电网抽入从每 5 tick 一次改为每 20 tick 一次；
- 内部能量改为 20 tick 批量注入，容器写入频率降为原来的 1/20；
- 容量只读一次并缓存，空存量直接跳过网络查询。

### 新增

**太古石炉进入 JEI 烧炼分类**

此前虽然能处理电炉配方，但 JEI 的“烧炼”页签里看不到它。现已把太古石炉注册为烧炼配方的可用机器。

### 视觉

**寰宇执序者恢复为常规多方块外观**

该版本的体积渲染（独立帧缓冲 + 自定义着色器）在实机上出现定位偏移与画面黑块，已整体移除：着色器资源、后处理管线、专用渲染器全部删除，机器回到标准多方块外壳渲染，不再有额外的 TESR 开销。

### 配方调整

| 等级 | 机器 |
|---|---|
| MAX（EUt = MAX 级，2400 tick，`gtlcore` 的 MAX 级组件） | 十一维聚合塔、万界之瞳、超恒星苍穹煅天舰、超稳态环形奇迹空间站、寰宇执序者、时序共振增幅阵列、时序推演阵列、永恒、奇点、造物、创生、虚无、星煅、天工、寰世 |
| OpV（EUt = OpV 级，1200 tick，OpV 级组件） | 墟渊化学蚀骸仪、秩数衍构 |

- **大型冶炼炉**：取消组装机配方，只保留工作台合成。
- 其余机器（量子编织主、寰宇物质虹吸器）配方不变。

### 移除

- **超时空加速中枢**（`hyperspace_time_acceleration_hub`）：机器类、结构定义、合成配方、注册项、创造模式入口与中英翻译键整组删除。

### 升级提示

1. **存档前先拆掉超时空加速中枢**，否则该方块与其内容会丢失。
2. **删除 `mods` 里的旧 JAR**（`GTL-Supb-4.8.jar` 及更早版本），只保留 `GTL-Supb-4.8.1.jar`，同 MOD ID 双份会导致启动崩溃。
3. 已放置的机器无需拆机；配方与本体的机器逻辑变更不影响存档中的运行状态。
4. 大型冶炼炉此前用组装机合成的玩家，本次更新后改为工作台合成，工作台配方未改动。
