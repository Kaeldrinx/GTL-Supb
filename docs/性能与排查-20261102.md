# 性能与排查 — 2026-11-02

## 性能设计要点

| 机制 | 说明 |
|---|---|
| 空闲三态 | IDLE 无配方 → 退订休眠（0 tick）；有配方 → 运行；缺电/输出满 → 等待。 |
| 搜索节流 | `START_INTERVAL_TICKS = 5`：两次"取新配方"至少间隔 5 tick，运行中不搜索。 |
| 单配方批次 | 每条批次只含一条配方，并行核算只针对该配方自身材料，账目与成本都最小。 |
| 空结果退避 | 空搜索后 `2→4→8` tick 退避，命中即复位。 |
| 查询策略 | 已移除 `recipeQueryBudget` 与 `planCacheTicks`。普通单配方路径使用 gtlcore 首条候选；多配方合并路径完整迭代，由并行与 EU 预算终止。 |

## 常见问题排查

| 症状 | 排查路径 |
|---|---|
| 合成延迟大 | 检查 `START_INTERVAL_TICKS`、空结果退避是否被外部改小；确认没有每 tick 全量搜索的调用残留。 |
| 产出与请求不一致 | 检查扣料是否与开跑 1:1（`startOneBatch` 的 match→handle→入列）；确认批次内是否被跨配方均摊。 |
| 材料被平分 | 旧 FAIR 分配已移除；若仍出现，检查是否多条绑定共用输入池（逐槽供料路径）。 |
| 机器"拆掉重放才跑" | 样板绑定缓存过期 → 见 `样板绑定系统` 的失效/解绑/降级；确认结构事件与推料唤醒。 |
| 输出满卡住 | 结算前 `matchRecipeOutput` 失败会保留批次重试，不会吞产物。 |

## 日志键

- `[并发批次]`：批次执行异常隔离。
- `[样板绑定]`：绑定解析/拒绝/降级诊断。
- `[样板总成]`：推料落地与唤醒。
- 历史 `[配方自愈]`、`[配方查询]` 已随死代码清扫移除。
