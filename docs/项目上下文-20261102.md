# 项目上下文 — 2026-11-02

## 定位

GTL-Supb（`gtlsupb`）是 Minecraft 1.20.1 的 GTCEu 附属模组，提供一批高端多方块机器与跨模组集成
（AE2 样板、FTB Quests 任务、Jade 信息面板）。当前版本 **4.1**。

```powershell
.\gradlew.bat spotlessApply build --offline --console=plain
```

产物：`build/libs/GTL-Supb-4.1.jar`。回归测试 `recipeSafetyTest`（纯 JDK，`.\gradlew.bat recipeSafetyTest`），当前 32 项断言。

## 运行入口

- 主 Mod 入口：`@Mod("gtlsupb") GTLSupb`（`common/GTLSupb.java`），按环境分发到代理。
- 附属入口：`@GTAddon(GTCEu.class) GTLSupbAddon`（GTCEu 生态注册）。
- 装配主链：`CommonProxy` → 注册机器、集成、网络包与配置。

## 模块结构（主要）

| 目录 | 职责 |
|---|---|
| `api/machine/logic/MutableRecipesLogic.java` | 机器配方逻辑核心（并发批次、合并、消耗、状态机） |
| `api/machine/IPatternAssemblyHatch.java` | 样板总成仓接口（配方绑定、逐槽供料） |
| `common/machine/GTLSupbMachines.java` | 机器注册（40 个定义，成对的 `XxxPattern` + `XxxPatternLayers`） |
| `common/machine/multiblock/part/PatternAssemblyPartMachine.java` | 样板总成仓实现 |
| `common/machine/multiblock/*` | 各多方块机器与专用逻辑（零能耗、执序者、模块基类等） |
| `mixin/` | 对 GTCEu/gtlcore/AE2/Jade 的注入 |
| `integration/jade/`、`integration/jei/` | 信息面板与 JEI 集成 |
| `utils/` | 纯 JDK 数值/异常辅助（`RecipeSafety`、`RecipeCalculationHelper`） |
| `config/ConfigHolder.java` | 配置项（合并预算、配方查询上限等） |
